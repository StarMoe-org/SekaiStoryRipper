# ADR-0005: 密钥由用户提供，不分发任何游戏资产

- **状态**：accepted
- **日期**：2026-09-23

## 背景

清单和（日服）API 使用 AES-128-CBC 加密。把密钥写进开源代码最方便，但相当于分发密钥。测试需要真实数据，但仓库和发布包里放入游戏资产或其裁剪片段同样有风险。

## 决策

- 代码和仓库里不带密钥。用户通过环境变量 `RIPPER_AB_KEY` / `RIPPER_AB_IV` 或配置文件 `[crypto]` 提供，自行从合法持有的客户端取得。
- 兼容已解密的清单：`ripper manifest --from-file` 导入后不需要密钥。
- bundle 的反混淆规则不是密钥，写在代码里。
- 仓库和发布包里不放任何游戏资产或派生资产。测试只用合成数据；需要真实数据的验证通过本地缓存进行，仓库里只放哈希和统计值。
- 输出目录默认被 `.gitignore` 忽略。

## 后果

- 正面：仓库本身不包含任何受版权保护的数据或密钥。
- 负面：首次使用多一步配置；真实数据测试只能在本地跑。

以上不构成法律意见。

## 复审条件

官方提供了公开的数据接口，或权利方对工具提出要求时。
