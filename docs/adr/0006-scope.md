# ADR-0006: 范围：剧情类型与客户端内置资源

- **状态**：accepted
- **日期**：2026-09-23

## 背景

剧情回放涉及的资源分两类：CDN 上按需下载的 bundle，和随客户端安装包分发的内置资源（对话框、Telop、转场粒子、shader、TMP 材质等，位于 `Data/data.unity3d`）。

## 决策

- 支持的剧情类型：主线、活动、卡面、特别篇。区域对话和角色自我介绍列为后续工作。
- 客户端内置资源不由 ripper 处理，由用户从自己的客户端导出后交给 sse。
- MV 只在 episode 索引里留占位条目。

## 后果

- 正面：ripper 只依赖 CDN，无需读取安装包。
- 负面：sse 需要单独准备 UI 素材。

## 复审条件

需要让 ripper 一站式产出 sse 所需的全部素材时，可以增加 `--local data.unity3d` 输入源。
